# Contributing

Thank you for improving Meterial Extra.

## Before opening a pull request

- Keep the project dependency-free unless a dependency has a clear, documented benefit.
- Use original demonstration content only.
- Do not submit personal data, credentials, production URLs, private branding, analytics identifiers, or uploaded customer media.
- Preserve keyboard access, visible focus, responsive layouts, and reduced-motion behavior.
- Test current Chrome or Edge at desktop and portrait widths.
- Explain the user-visible problem and the resulting behavior in the pull request.

## Code style

- Use semantic HTML before adding ARIA.
- Keep CSS tokens in `tokens.css` and reusable color roles in `theme.css`.
- Prefer small functions and explicit state.
- Avoid adding animation that lacks a reduced-motion fallback.
- Do not silently replace a control's accessible name with an icon.

## Demo content

Demo articles, names, dates, statistics, and links must be fictional or generic. New content should not resemble a real person's private site.
